# 辞曲新境四种歌词场景的还原与町景 DXR 移植方案

2026-11-19 · 移植设计与实施记录。移植前的基线为 Spectrum `4c2d321`、folia-major `6ee9404f7957b8ea841a46bad8b085a5a604a3cf`（0.7.29）、DXRDemo `7e3b814`。已将指定的 folia-major 工作树由 `581ae3c2` 快进至上述提交。移植前 Spectrum 的 NOTICE 引用 `4c4c3c3b`，相隔 55 个提交，同一版本号下也要按提交固定输入。

实施保留四个既有模式 ID。花火、隐喻、雾笺沿用原生 D3D12，复用上游编排和材质。町景升级为 DXR 硬件专属，三个布景共用一个路径追踪后端。以**正交镜头下的几何和歌词对照帧**作为调整光照与降噪的基准。上游几何、文字、运动可逐项按像素核验，路径追踪增加的间接光、透射和反射另做画质验收。

## 已接入的渲染与资产

三个布景用同一硬件 DXR Tier 1.0 / SM 6.3 后端。首选 NRD，用户选择 RR 时再查询 NGX。世界空间歌词牌、材质、演员实例与相机都参与主射线和二次命中。湿膜和水洼采用不同的 GGX 粗糙度，井盖蒸汽、沿檐滴水、光柱、景深与屏幕字幕在降噪后合成。SDR 使用 PBR Neutral 色调映射，HDR 保留高亮交给宿主输出。换布景复用工作分辨率资源、管线和降噪上下文，改窗口尺寸保留几何加速结构。

| --- | ---: | ---: | ---: |
| 便利店 | 88,222 | 717,644 字节 | 6 |
| 加油站 | 57,032 | 411,106 字节 | 5 |

几何与布景装饰采用固定种子烘焙。自动选景、歌词、运镜、门、车辆及天气时钟由原生运行时驱动。上游可随歌曲重新生成的整个几何布置仍使用烘焙变体。三种 2D 模式在后台执行固定版本的上游编排并生成原生绘制数据。MRT 墨场、玻璃折射和雾层都在 D3D12 上渲染。其他模式沿用各自的时域重建路径。

### 离屏运行基线

在 RTX 5070 Ti 上以 1920×1080、固定夜雨和同一相机构图测试，每景 16 帧，前 4 帧预热。D3D12 时间戳覆盖路径追踪与当前降噪，不含歌词面板绘制、镜头后处理、交换链和显示器。NRD 的三景 GPU 时间中位数依次为 12.57、12.18、12.61 ms；DLSS RR 为 13.45、12.32、13.39 ms。进程本地显存增量分别为 NRD 983/847/845 MiB、RR 861/707/725 MiB，首景包含进程内首次使用开销。每个像素都通过有限值检查。带两个屏幕分量的运动探针验证了 X/Y，独立 RGB 探针核对了颜色通道。原版屏幕四角在三景、横竖屏和漂移取景下最大投影差低于 0.001 px。这项误差只衡量几何，不衡量最终色差。

DXR 管线字节码更新后，首次驱动编译的后端构造实测 2.39 秒；缓存预热后重复构造约 0.1 秒。实际换布景复用同一个后端。首次使用 RR 还会产生独立 NGX 初始化开销。硬件基线是 DXR Tier 1.0 / SM 6.3，NRD 使用 SM 6.0 DXIL。AMD/Intel 实卡、壁纸、HDR 显示器及交互仍需实机覆盖。

最终 Release NativeAOT 宿主离屏验证在 640×360 下测得首次进入便利店 NRD 2.506 秒，进入加油站和九龙三维场景分别为 22.3 ms 和 20.1 ms，首次切换到 RR 为 1.584 秒。计时从请求发出到包含目标场景的帧完成宿主调用；包含场景准备、编译或 SDK 首用成本。三种布景均通过逐像素浮点有限值检查，调整窗口尺寸保持 BLAS/TLAS。町景四条组合与花火、隐喻、雾笺、经典歌词共八组，各在 36 个稳定帧内测得渲染线程托管分配为 0 B。旧存档默认值与七项场景设置的源生成 JSON 往返也在 NativeAOT 中验证通过。

### 上游画面对照与兼容性回归

- 花火全部 50 个预设使用相同歌曲、640×360 视口和 17.6 秒位置，对照上游 WebGL 与原生 D3D12。在共同场景区域（去除宿主字幕）以 sRGB 全范围归一化，三通道平均绝对误差中位数为 5.217%，范围 2.601%–10.666%，差异最大的是 `shakudama-nishiki`。这项比较覆盖一个时间点；另对 1,000 次确定性跳转采集到 267,435 个精灵，写入线程托管分配为 0 B。
- 隐喻分别回读墨量与墨色两个 GPU 目标，在线性浮点空间测得峰值 7.699 与 1.296。在相同 17.6 秒样帧、排除底部公共字幕后，sRGB 三通道平均绝对误差依次为 5.19%、5.73%、5.90%。
- 雾笺九组窗外与玻璃均用 640×360、17.600 秒对照，归一化 sRGB 全图平均绝对误差为 1.7%–2.9%。共享背景模式由宿主送入底图，根据相同底色比较透明合成。1,000 次确定性跳转生成 2,404,561 个笔画等实例，写入线程分配 0 B。车辆颠簸、雨滴碰撞、凝露扫掠与融雪再流动采用原生程序化近似，尚有运动差异。
- 三个町景都使用正交路径追踪、上下游一致的牌面锚点。旅馆「NO VACANCY」使用两张上游灯箱原图，副歌进出已做 GPU 回读。窗户厚度、路径透射和反射改变了便利店内亮度与街面倒影。
- 在 Sonic 的独立 D3D12 队列上，FSR、XeSS 与 DLSS 三种已有重建各运行 96 帧，在四个时间点对照逐帧等待 GPU 的基线。每种模式均通过，模拟 SDK 调用失败后的队列清空和资源替换也通过。

## 四个场景的修正范围

| 模式 | 移植前基线与上游差异 | 移植单元与交付 |
| --- | --- | --- |

| 隐喻 `metaphor` | `FoliaMetaphor.Figure` 有三种绘制分支，关键词只选一组墨场值。上游有 19 种科学图形、8 种镜头和 cut/flood/smash 三种转场，关键词各自的色墨能相混。 | 移植 program、layout、camera、figures、shapes 和 palette。重建紧/宽双通道字形与双渲染目标，分别存墨量/网点/强调墨和预乘色墨；显影移植 8 Hz 流场、阈值、纸粒、反相和漫墨。输出镜头索引、字形包围盒、两张中间纹理及显影帧，检查近摄、荷兰角、两个不同色关键词重叠。 |

其他三景可沿用现有 Sonnet、Tempera 等模式的做法，把上游纯函数在构建时固定、在换歌/字体/视口时准备为不可变计划。每帧只读数组和已分配缓冲。Pixi、Three、WebGL 的画笔、混合、纹理采样和 pass 顺序由对应原生实现承接。转写的公式要与上游单测使用相同的向量。字体固定同一文件、字重、字距和 grapheme 分段；缺少离线鼓点、段落或人工编排时，参考与原生两端同时使用同一份降级输入。Spectrum 实时频带触发单独测试。

## 町景模型、屏幕与镜头

**移植前的默认便利店屏幕误差（历史基准）。** 在 1920×1080、歌曲时间 0、默认视角、无抖动的条件下，运行上游 `MachiCamera`，按 `konbiniScene.ts` 重建 framing points，将 `store.ts` 的正面挂点和 `konbiniSigns.ts` 的有效屏面四角投影。Spectrum 侧按 `FoliaMachi.Camera(0, 16/9)` 和现有网格的屏面坐标做相同计算。坐标原点在左上，以下为四舍五入后的 CPU 投影结果。

| 1920×1080 画面 | 屏面中心 (x, y) | 屏面轴对齐包围盒宽 × 高 |
| --- | --- | --- |
| folia-major | (996, 393) px | 618 × 212 px |
| Spectrum | (995, 287) px | 433 × 134 px |

移植前屏心高出 **106 px**，可见字面宽度少约 **30%**。这组测量只覆盖正面屏的几何投影，未包含像素着色、辉光、遮挡或显示设备。本次重做了模型与取景，修正后的投影误差见上方离屏基线。

制作时建议从固定版本的 Three 场景构建器直接导出一套参考几何。截取静态合批前的节点名、局部矩阵、BufferGeometry 顶点/索引、材质槽和实例变换，连同发光面、屏幕 UV、枢轴及相机 framing 写入 Blender 可读的参考文件。运行时生成的每歌变体另外输出 seed 与可选件清单。把参考几何设成 Blender 工作文件中锁定的参考集合，叠着它替换道具。底座、楼体、屋顶屏和店招能直接沿用源网格的部位优先沿用；这样能从差图定位具体换错的部件，也为加油站与九龙提供了同一入口。

1. 从 `machi/scenes/*/layout.ts`、各 scene 的 framing points、牌面挂点和演员轨迹生成版本化清单。用米为单位，Folia 的 Y 向上、+Z 朝店前、+X 朝右；显式定义与 Blender Z-up、glTF Y-up、D3D 矩阵、UV 和绕序的一次性转换。每个布景都输出世界坐标和参考像素坐标的锚点。
2. 便利店按上游 12 × 12 × 0.6 m 底座、6.2 × 5.8 m 店面、屋面 3.42 m、女儿墙 3.62 m 搭建。屋顶是三角柱广告塔，中心 X/Z 为 −2.2/−2.65 m，单面 5.6 × 2.3 m，下沿高 4 m，正面方位 45°。保留店前和右前玻璃、店侧实墙、自动门、停车位、路缘和两条相交道路。先用平光检查轮廓、遮挡和屏幕面积。
3. `RainyCorner.blend` 在工作副本中按部件提取。保留售货机、冰柜、货架、收银台、空调、自行车和路灯的可辨外形；位置、色板、店招文字和灯光由 Folia 决定。按最大支持缩放及最斜可见角检查剪影，螺纹、罐口、条码、价签和小文字优先烘入材质图集，字牌使用字面纹理。重复货品共享低模和材质；玻璃保留厚度、封闭性、IOR、透射与内外法线。门、车、风扇、旗帜单列节点，保留枢轴和上一帧变换。
4. 原始 GLB 实读为 **9,597,780 字节、368,734 个唯一网格三角形、340 个网格、3,727 个网格实例，展开 2,097,886 三角形**。90 个瓶盖展开 189,720 面，六组 PET 瓶合计 846,360 面，单件路牌文字 65,096 面。优先处理这三类。第一轮建议目标为唯一三角形 ≤80,000、展开 ≤250,000、实例 ≤500；同时记录材质数、显存和光源采样表大小。如果合并货架显著扩大 BLAS 或损失近景轮廓，按实测调整。GLB 尺寸本身无法定位加载瓶颈。
5. 构建工具把审核后的 Blender 导出物转换成固定格式的运行时网格、实例、PBR 材质、灯光、字牌槽位和压缩纹理。构建时预计算包围盒、静态灯面数据和几何分组，按内容哈希失效。随应用分发布景所需资产及许可；Blender、作者源文件、供体整库与 SharpGLTF 导入依赖留在制作或构建侧。保存可重放的简化脚本和导出版本，正式构建可直接消费受版本控制的资产。
6. 移植 `engine/camera.ts` 的正交取景、构图点适配、字幕预留、缩放裁切和运镜。便利店默认方位 45°、俯角 31°、缩放 1.58，镜头水平活动 ±75°。默认关闭自动运镜，启用后按上游多周期漂移；场景、时段、天气的默认值均为 auto。按上游支持自定义静止视角、拖拽、平移与回正；交互经 UI 发命令到渲染线程，壁纸态保持不抢焦点。加油站、城寨使用各自的默认 framing。
7. 移植 director、boardLayout、lyricScreen、ledStrip 和各场景 signs。便利店屋顶三面屏显示当前行或曲名卡，按字宽选 1–3 行，店招 LED 滚动下一句，海报与立牌显示各自内容。上游大屏字面半图宽 1280、横向 150 格、换行 0.3 s，牌面提前 0.12 s、唱完保留 2.6 s 后可回曲名卡。加油站停车场保留广告货车侧屏（当前行）、出租车顶灯（下一句等）、价格柱（播放进度）及汽车旅馆立牌（曲名/副歌提示），九龙保留巷道、酒吧字牌及显示下一句的全息投影。复刻自动门、车流、双闪、旗/风扇、蒸汽、灯具和种子化布置；昼/昏/夜与晴/雨/雪/雾按上游规则组合。环境时钟随暂停，歌词目标支持直接 seek。

## DXR、完整降噪与宿主接线

| 责任 | 采用的源与适配 |
| --- | --- |
| 设备、队列、帧槽 | Spectrum 的 `GpuDeviceLease`、`GpuGraphics` 继续拥有设备、队列、fence、交换链与输出。按所选 adapter 查询 Device5、GraphicsCommandList4、DXR tier、shader model、SDK 与资源格式。实施采用 `lib_6_3` 的硬件 TraceRay，保持 Tier 1.0 入口。拒绝软件适配器。 |
| PT 核心 | 从 DXRDemo 的 `DxrSceneBackend`、`DxrShaderTable`、GPU 场景上传、`SceneTrace.hlsl` 与 `Path*.hlsli` 提取索引实例几何、BLAS/TLAS、PBR/介质、Sobol、灯面采样、环境分布和 MIS。供体每次 Trace 结尾调用 `End() → ExecuteCommandList → SignalAndWait` 并立即读取 GPU 时间。将它改为宿主命令列表录制，利用帧槽 fence 延迟读取时间戳；同时按帧槽分开可写常量、descriptor 和跨帧历史，避免移除等待后覆盖在途数据。静态网格共享 BLAS；刚体更新 TLAS 变换，形变对象按可更新 BLAS 或专用合成路径处理。实时路径使用发光面和场内灯采样与 MIS。供体的 ReSTIR 和光子焦散属于后续可选实验。 |
| 正交投影 | 每个像素的主射线从自己的成像平面位置出发，方向平行。当前和上一帧均传真实未抖动 view/projection、正交范围和 near/far；jitter 只改变采样位置。主表面、天空、运动实例、反射/透射虚拟表面都输出对应的重投影。NRD 使用 viewZ 等自身所需 guides，宿主另收常规 0..1 depth 与不含 jitter 的“当前到上一帧”输入像素位移。町景独占自己的去噪与重建。在宿主图像编码前提交线性图像，避免重复执行全局时域重建。 |
| 官方 NRD | 移植 `External/NRD`、`Native/Reconstruction/Nrd.cpp`、`NativeNrd`、`PathTracingResolve`、`StablePlaneDenoiser`、`StableReconstruction.hlsl` 及对应依赖。PBR 路径保留 RELAX_DIFFUSE_SPECULAR_SH 的分离漫反射/镜面辐射、命中距离、方向矩、法线/粗糙度、viewZ、motion、材质因子。完整消费 SDK 返回的 dispatch 序列。主表面剩余贡献、首个平滑反射和透射各有历史与虚拟几何引导，合成时加回当前帧确定性项。门窗边缘、移动遮挡与反射文字应成为专门测试样例。 |
| DLSS Ray Reconstruction | 通过 NGX 能力查询在支持设备上执行 RR，传入正交矩阵、抖动、运动、法线/粗糙度和材质引导。请求 RR 的设备若无法执行则切回 NRD；设置页报告实际运行路径。 |
| 动态发光歌词 | 使用已有字形 atlas 生成世界空间动态材质，PT 主射线与二次命中都能采样。将首见屏幕的确定性发光分量保留到 NRD 后合成；间接照明和反射按对应路径去噪。文字/翻牌更新的是纹理、时间和必要的发光采样权重，避免逐字重建 AS；用材质 ID、遮挡及局部 reactive/history rejection 抑制拖影。对直接可见字面同时保留 PT 可见性、过滤和景深约定。 |
| 合成与资源 | 线性 FP16 场景 → 支持的单次可选时域重建 → 上游对应的镜头/光晕和宿主 SDR/HDR10 输出，明确每个 pass 的输入分辨率及色域。已在 PT 内计算的反射不再加一次平面反射；Bloom、曝光和输出传递各指定唯一执行位置。保留上游风格化雾和粒子，并提供按深度遮挡的合成。动效、后处理各自有中间图供核对。 |

Spectrum 的 D3D12/DXGI 包目前为 Vortice 3.6.2，供体为 3.8.3。先用最小 state object、shader table 和一块玻璃验证 API/ABI。现有 `ShaderCompiler` 使用 D3DCompiler；扩展同一构建入口以 DXC 编译 SM6/DXIL 库，登记 `ShaderCatalog` 和正式预编译工具，固定编译器版本、展开的 include、宏、导出名、目标与选项。核验 Agility 激活及 NativeAOT/MSIX 中的 x64 DLL、官方 NRD 和许可。资源契约、根签名、shader table 或固定状态变化时升级管线键，驱动相关对象按设备隔离；在冷路径创建与预热。

町景的美术基准包含 `materials.ts` 的四阶卡通渐变、主题色插值和积雪，以及 `postPasses.ts` 的深度墨线、贴地薄雾与横向光条。建议在材质中保留 Folia 色键和分阶参数，去噪后用分离的漫反射照明与材质信息还原色阶，玻璃和湿地保留连续镜面/透射响应。这样在开启 PT 时仍能识别原画风。按 `post.ts` 核对实际 pass 顺序、透明背景和镜头选项，以无辉光、无雾、无景深的中间帧标定光度，再打开镜头效果。店侧独立跑马灯按上游 4096 × 96 字条缓存，内容变化时重画，每帧只推进滚动采样位置。

### 调度、故障与存量设置

- 布景缓存按场景/资产版本/设备维护。歌词内容缓存按歌曲/字体/视口维护。换歌和调字号只更新歌词计划、牌面和确实依赖种子的实例。异步解码与分段上传带代号和取消；渲染线程在新场景就绪时原子替换，过期结果丢弃。峰值核对新旧场景重叠所需显存。退出时先停止生产，再等待最后消费者 fence 后退役资源。切出町景停止其 dispatch 和后台工作。
- 调整尺寸、DPI、HDR、设备更换、场景切换与跳播分别定义重建/清历史范围。暂停冻结演员和环境时钟；恢复首帧用同一姿态。动态门和车辆要保留前一帧实例矩阵，遮挡显露区域拒绝历史。稳定帧复用 descriptors、常量、命令列表和缓冲；测量分配、GPU 时间与显存后再报告收益。
- `FoliaLyricMode="machi"` 保留原值。能力判断走同一入口，覆盖设置、持久化恢复及所有模式切换入口。无硬件 DXR 时禁用选择并显示原因；恢复旧存档时保留请求值，运行期间显示原有可用歌词模式并标明原因。建议临时显示 `classic`。NRD 初始化失败显式报告，可回到已有歌词模式并允许重试；仅已验收的有意选择才标记为 PT+RR 或 PT+NRD。设备换回后可恢复町景。
- 新增子场景及必要的镜头/环境配置，默认采用上游默认值，放入町景专属折叠组。同步 AppSettings、SaveSetting、DataJsonService 双向映射、VM、两份 resw。默认值和老 JSON 做源生成往返测试。三个新 2D 模式也按各自上游 tuning 核对影响画面的控制项。排除项目已移除的 still。

**建议的初始判据，实施时先记录基线。**

- 几何使用无 PT 噪声、无景深的 ID/深度通道；以 1920×1080 为基准，静态锚点最大误差 ≤1 px，屏角、字面基线、门窗和屋顶逐项列出。另测 9:16、21:9、100%/150% DPI 和侧向视角。记录对象掩膜与遮挡差图，防止少了整个道具却通过全图相似度。
- 歌词事件、镜头 ID、分行和逐字顺序对照上游输出；离屏 60 Hz 采样时事件边界误差 ≤1 帧。对 2D 场景记录线性颜色与统一 SDR 显示变换后的逐层差图，分别报告字形边缘误差、笔迹覆盖、粒子及镜头位置。首次基线标定后为各层固定容差，避免用一个全图 SSIM 放过缺失内容。
- PT 光照用同一低模、相机、灯光的高采样参考图检查；固定 1/2 SPP、预热帧数和运动轨迹，分别测主表面、玻璃反射、透射误差及换字后残留曲线。回读首见发光通道验证旧字及时移除，贴近窗框测遮挡切换；测试静止、运镜、自动门、暂停、seek、切镜与尺寸变化。按帧记录实际 NRD dispatch、各历史 reset、D3D12 debug 层及非有限值。
- 同一硬件/驱动比较供体原模型和简化模型的冷/热进入。分别计时磁盘读取、CPU 解包、上传、BLAS/TLAS、state object、NRD 初始化、首个完整离屏帧，采集峰值与稳态显存、GPU 时间 p50/p95 和稳态托管分配。建议先以简化模型冷进入耗时较原模减半为目标；报告绝对毫秒并说明缓存条件，任何硬件档位承诺都等实测后再定。
- 离屏探针使用 `new SpectrumAnalyzer(captureAudio: false)`，注入合成缓冲。临时脚本、金图、差图、日志放在忽略的 `.tools/`；正式资产与构建脚本可独立工作。显示器 HDR 观感、字体在真实 DPI 的可读性、运镜时歌词拖影、壁纸焦点及实际呈现帧率由用户实机验收。
